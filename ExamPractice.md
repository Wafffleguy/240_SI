### Section 1

For the following three problems, write one of each loop in your code editor. This is coding practice, which means that your code should:

2. Do the correct steps for each problem
3. The output of your program should look right (formatting does not have to be perfect).


### Problem One: 

Write loops that will list every number from one to 25, and then display the sum of those numbers. 




### Problem Two: 

Create loops that will list every number from one to 50 that is divisible by $3$, and every number from 50 to 100 that is divisible by $7$. 




### Problem Three:

Create loops that will repeat an input character back at the user until they enter `Q`. You can assume the first character will not be `Q`.

### Problem 1

### Problem 2

If a character is a 'Y' or a 'y', output "Congratulations!". Otherwise, if the character is a 'N' or 'n', output "Woah!". Finally, if the character is neither a 'Y' or 'y' or 'N' or 'n', output "Dang."




### Problem 3
