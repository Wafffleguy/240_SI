# CSCI 240 - Supplemental Instruction 
### Flow Chart Conversion
---

Given the below set of steps *or* coding segment, convert the steps into a flow chart.


---


### Set One:


1. Declare an integer $x$ and take in some input. 
2. If $x$ is less than $50$
    - Pass: Output $x$ and continue
    - Fail: Do not output $x$ and continue
3. If $x$ is greater than $30$
    - Pass: Subtract $10$ from $x$
    - Fail: Add $10$ to $x$
4. If $x$ is less than $25$
    - Pass: Do nothing
    - Fail: Do nothing


### Set Two:

As long as we input a positive $x$ value, if $x$ is greater than $4$, we want to check if it is less than $16$. If both conditions pass, we output it. If not, we do nothing. 

### Set Three:

I want to output $x$, which is an input integer, as long as $x$ is not negative. I want to add up all of the input $x$ values, and output that **after** outputting all $x$ values. 

### Set Four:

If an input integer $x$ is greater than $16$, we want to decrement it until it is less than $20$, then output it. Then if we did not decrement $x$, we want to increment $x$ $5$ times and output it.
