# CSCI 240 - Supplemental Instruction

### Formatting Practice

---

Given the example outputs below and the other requirements, format the output of your program to match! 

---

### Variable Declaration:

```c++
int A, B;
A = 75;
B = 8;
```

### Output:

```
Our variable for A holds 75

Our variable for B holds  8
```

---

### Variable Declaration

```c++
double GPA = 3.5;
```


### Variable Declaration

```c++
float length = 7.8;
float width = 6.5;
float area = length * width;
```

### Output

```
The length of the field is   7.8 meters
The width of the field is    6.5 meters
The total area is           50.7 meters
The area rounded up is        51 meters
```
