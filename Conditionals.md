# CSCI 240 - Supplemental Instruction
### Conditionals
---

For the following prompts, create a set of if-else statements that result in the desired outcome. They do not need to be in real code, but a set of steps is expected. 

## Example:

I want an integer, called $x$, to be between $30$ and $40$. 

### Answer
```
if x < 40 
{
    if x > 30{
        //x IS between 30 and 40
    } else 
    {
        //x is not between 30 and 40
    }

} else 
{
    //x is not between 30 and 40
}
```

## Problems:

Write an if statement for each of the following problems that passes the desired integer (A pass is when the condition succeeds).

1. I want an integer greater that $500$, and less than $3000$. 

2. I want an integer that is divisible by $3$.

3. I want an integer that is NOT divisible by $3$.

4. I want an integer that is divisible by $5$ and greater than $50$. I do not want $50$. 

5. I want every integer EXCEPT $47$. 

6. I only want $47$.
