### Solutions

Most of these will be exactly what they write, but as long as it does the appropriate operation it should be okay. Make sure they use semicolons. 

---

```c++
int x = 10, y = 10;
int z = x * y;
```
This one is easy enough, they can also declare the variables separately. 

---

```c++
char G = F;
```

---

```c++
float A = 3.5e20;
int B = 105;
A = A + B;
```
Make sure to ask if the result could be stored in $B$. 

---

```c++
int remainder = 50 % 11;
```
It is incredibly important that they know the difference between the division types. 

---

```c++
int quotient = 50 / 11;
```
