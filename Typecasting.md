# CSCI 240 - Supplemental Instruction

### Typecasting

---

Given the below situations, use typecasting when necessary to get the desired result. 

---

### Variables

```c++
float A, B;
int C, D;
A = 8;
B = 12.7;
```

### Goal

Store the `remainder` of B divided by A in C. Store the `quotient` of B divided by A in D. 

---

### Variables

```c++
double A = 9.3;
int B;
double C;
```

### Goal

Store the whole number value of A in B, and the decimal part of A in C. 

---

### Variables

```c++
float A = 23.4;
float B = 30.0;
int C;
int D;
```

### Goal

Store the whole number value of the product of A and B in C, and the whole number value of the sum of A and B in D.
